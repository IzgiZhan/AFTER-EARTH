## О чём игра

**Жанр:** 2D top-down выживание с волнами противников и прокачкой системы роботов.

**Одна фраза:** людей на Земле не осталось — последний выживший восстанавливает цивилизацию руками роботов, которых он сам построил и настроил.

**Что автоматизирует игрок.** В начале игрок всё делает сам: выходит за ресурсами, обрабатывает грядки, отбивает мутантов у ворот. За выживание в волнах начисляются токены, на них в терминале покупаются три типа роботов:

- **Робот-грузчик** — сам уходит за ресурсами и сдаёт их на склад;
- **Робот-фермер** — сам обслуживает контейнерный огород;
- **Робот-страж** — сам держит оборону у ворот.

Каждый тип прокачивается до 5 уровня: выше скорость, грузоподъёмность и урон, меняется внешний вид. Токенов всегда меньше, чем целей, поэтому игрок решает, какую часть работы отдать машинам первой. С пятой волны вручную успеть невозможно — без автоматизации игра не проходится.

**Win / lose / score.** Победа — довести показатель «Цивилизация» до 100%, расширив зону до 5 из 5. Поражение — смерть от мутантов или падение крепости. Счёт — число пройденных волн и время выживания, рекорд сохраняется.

## Как играть

**Управление:**

| Клавиша | Действие |
|---|---|
| WASD | ходьба |
| Shift | бег |
| Мышь + ЛКМ или Пробел | удар |
| E | действие: терминал, мастерская, шлюз |
| 1–9, 0 | выбор пункта в терминале |
| Esc | пауза и настройки |

**Цель:** выжить как можно дольше и восстановить цивилизацию.

**Длительность сессии:** 3–5 минут до первого видимого результата автоматизации, 15–25 минут до 100% цивилизации.

**Обучение:** отдельного обучающего экрана нет. Цель и управление считываются за 60 секунд: панель подсказок внизу экрана, контекстные советы слева, подписи на всех объектах бункера.

## Запуск

**Web (рекомендуется).** Открыть https://izgizhan.github.io/AFTER-EARTH/ в Chrome или Firefox. Установка не требуется, интернет нужен только для загрузки страницы — сама игра работает офлайн.

**Локально из сборки.** Скачать папку `build/web/`, запустить локальный сервер:

```
python -m http.server 8000
```

затем открыть `http://localhost:8000`.

**Сборка из исходников.** Установить Godot 4, открыть `project.godot`, затем Project → Export → Web.

## Известные баги

- Баланс поздних волн не отполирован: после 8 волны сложность растёт резко.
- При 150+ мутантах и 10 роботах на экране частота кадров падает до 20. В базовой фазе держится 60.
- Сохранение хранится в браузере: при очистке данных сайта прогресс теряется.

## Производительность

Тестировалось на ноутбуке со встроенной графикой, Windows 11, Chrome:

- загрузка WebGL-сборки — менее 15 секунд;
- 60 FPS в бункере и при обычных волнах, не ниже 20 в пиковые моменты;
- 10 минут игры без вылетов;
- сетевых запросов во время игры нет.
